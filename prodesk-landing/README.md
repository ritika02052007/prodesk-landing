- Dark / Light mode toggle (class on `<body>`, CSS variables)
- Hover effects on buttons and cards, scroll reveal, floating hero hexagons
- Sections: Hero, About, Services, Solutions, Stats, Why Choose Us, Open Roles, FAQ, Footer
